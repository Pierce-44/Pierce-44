I’m a Full Stack Developer at **Bounce Insights**, building **AI-powered, data-driven platforms** that help clients turn complex data into actionable insights.  
I specialize in creating **scalable, high-performance web applications** using React, Node.js, TypeScript, and AWS — with a growing focus on integrating **large language models (LLMs)** to enhance decision-making and user experience.

Previously, at **PageSuite**, I worked as a **Frontend Developer**, contributing to the development of a **Next.js-based e-edition web platform** and a **JavaScript Reader SDK** with interactive features, dynamic HTML templates, and touch interactivity for mobile and tablet devices.

<br>

## 🧠 What I’m Working On

- 💡 **Retrieval Engine** – a retrieval-based AI platform that processes surveys, files, and PDFs to deliver deeper, actionable insights.  
- 🤖 **AI-Powered Insights Features** – integrating large language models (OpenAI and other platforms) to automate analysis, summarization, and data visualization.
